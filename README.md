## 프로젝트 소개

부경대학교 인공지능 수업에서 다층 퍼셉트론(MLP)을 조사해 발표한 16쪽 분량의 자료입니다. 단층 퍼셉트론이 XOR을 표현하지 못한다는 한계에서 시작해, 은닉층과 비선형 활성화 함수가 왜 필요한지, 그렇게 만든 신경망을 역전파로 어떻게 학습시키는지 순서대로 설명합니다.

## 은닉층과 XOR

![입력층, 은닉층, 출력층의 연결 관계를 보여 주는 다층 퍼셉트론 구조 슬라이드](Resources/MLP-Structure.png)

단층 퍼셉트론은 입력 공간을 직선 하나로 나누므로, 두 입력이 다를 때만 1이 되는 XOR을 표현할 수 없습니다. 다층 퍼셉트론은 입력층과 출력층 사이에 은닉층을 둡니다. 발표는 이 구조가 XOR을 어떻게 표현하는지를 질문으로 던지고 다음 슬라이드에서 답합니다.

![은닉층에서 NAND와 OR를 계산하고 출력층에서 AND로 결합하는 XOR 구조와 진리표 슬라이드](Resources/XOR-Example.png)

XOR을 NAND, OR, AND의 조합으로 분해했습니다. 은닉층의 두 뉴런이 같은 입력으로 NAND와 OR를 계산하고, 출력층이 두 결과를 AND로 묶으면 XOR이 됩니다. 오른쪽 진리표는 네 가지 입력 조합에서 은닉층 값과 최종 출력을 차례로 따라갑니다.

다만 층을 쌓는 것만으로는 충분하지 않습니다. 선형 연산을 여러 번 합성해도 결과는 하나의 선형 연산이므로, 각 층의 출력을 비선형 함수로 바꿔야 은닉층을 둔 의미가 생깁니다. 이것이 다음 주제인 활성화 함수로 이어집니다.

## 역전파

학습은 네 단계를 반복합니다. 순전파로 현재 가중치의 예측값을 구하고, 목표값과 비교해 손실을 계산합니다. 역전파로 출력층에서 입력층 방향으로 각 가중치에 대한 손실의 기울기를 구하고, 이 기울기와 학습률로 가중치를 갱신합니다. 발표는 경사 하강법이 전역 최솟값을 보장하지 않는다는 점과, 깊은 신경망에서 앞쪽 층까지 기울기가 충분히 전달되지 않는 기울기 소실 문제로 마무리했습니다.
